# projeto_final_dio_formacao_bob
Desafio para desenvolver o Geo-Explorer, um projeto que usa o IBM Bob como apoio para criar, testar e documentar uma solução completa. A proposta é criar uma experiência de exploração de trilhas de aprendizagem. A pessoa usuária poderá consultar uma trilha, receber um desafio de código e gerar um certificado fictício.
